# Hot Spring hybride — bibliothèque 1.1.0

La nouvelle version ajoute neuf dilemmes, soit vingt au total. La version 1.0.0
à onze dilemmes reste disponible et les sessions enregistrées gardent leur
contenu figé. Le catalogue propose désormais 1.1.0 pour les nouvelles parties.

Suites débloquées : tarifs du rail après le monopole ; contrôle des voyageurs
après les gardes privés ; partage de l’eau après le puits ; agrandissement après
l’école publique ; consolidation après la concession minière ; audit après les
prêts garantis ; commission des horaires après les concessions aux journaliers.
Deux autres dilemmes apparaissent sous conditions : patrouilles lorsque la
Sécurité est basse, place du marché lorsque la Satisfaction est basse.

Chaque nouvelle issue comporte un gain, une perte et une chronique. Les images
existantes sont réutilisées comme références thématiques ; aucune nouvelle
illustration spécifique n’a été produite. Le barème familial reste à recalibrer.
La proposition de contenu V2 demeure distincte de cette bibliothèque.

Vérification : les 120 sessions artificielles ont toutes terminé, chacune en dix
Conseils, avec 119 ordres distincts. Les vingt dilemmes ont été rencontrés sur
l’ensemble de ces essais. Cela ne signifie pas que chaque session les joue tous,
ni que la durée de 150 minutes est validée. Le choix automatique consomme ici le
budget maximum ; la régie peut choisir la finale dès qu’elle est admissible.

Tests ciblés de progression, validation et catalogue réussis ; construction
Firebase réussie. Cette tranche ne constitue pas un déploiement Firebase.
